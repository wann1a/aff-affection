# FAIFAH Affection Bar v1.1 (SillyTavern)

Install: copy this whole folder (faifah-affection) into
  SillyTavern/public/scripts/extensions/third-party/
(or data/<user>/extensions/ on newer versions), restart SillyTavern, then enable it in Extensions.

มี 2 ค่า: ❤️ ความโรแมนติก และ 🤝 ความสนิท
- บอทปิดท้ายทุกข้อความด้วย [LOVE:+N] [FRIEND:+N] (แท็กเก่า [LIKE:+N] นับเป็น LOVE)
- แท็กถูกซ่อน แสดงเป็นชิป ❤️ +N  🤝 +N ใต้ข้อความ
- โหมดความสัมพันธ์ (19 แบบ) คำนวณจากทั้งสองค่า กดที่แถบด้านบนเพื่อดูแผงรายละเอียด
- ค่ารวมคำนวณใหม่จากแชททุกครั้ง swipe/แก้/ลบข้อความแล้วค่ายังถูกต้อง
- ตั้งค่าเริ่มต้น/สูงสุด/ขอบเขตต่อข้อความของแต่ละค่าได้ในแผง Extensions
